## 📋 Panduan Pemilihan Judul

### Judul yang Baik Harus:
- ✅ **Deskriptif**: Menjelaskan apa itu ADASISWA
- ✅ **Ringkas**: Tidak terlalu panjang (idealnya < 70 karakter)
- ✅ **Mudah Diingat**: Catchy dan memorable
- ✅ **SEO-Friendly**: Mengandung kata kunci penting
- ✅ **Profesional**: Sesuai dengan image institusi

### Yang Perlu Dihindari:
- ❌ Terlalu teknis atau rumit
- ❌ Menggunakan singkatan yang tidak umum
- ❌ Terlalu panjang (> 100 karakter)
- ❌ Tidak mencerminkan konten repository

## 🔄 Cara Mengubah Judul Repository di GitHub

1. Buka repository di GitHub
2. Klik tab **Settings**
3. Di bagian **General**, ubah **Repository name**
4. Klik **Rename**

**Catatan**: Mengubah nama repository akan mengubah URL-nya!
